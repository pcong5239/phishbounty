Notes on documentation domains

A short reading list, updated occasionally.

Reserved domains exist so that written material can show a realistic address without pointing at anyone's live service. Example Brand, the placeholder company used throughout these notes, is one of those conveniences: it has no customers, no login, and no support desk.

Why placeholders matter

When a tutorial borrows a real company's address, readers eventually type it in. Reserved names avoid that entirely, which is why standards bodies set them aside in the first place.
